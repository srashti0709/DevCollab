
# Issue Analytics Metrics

| Metric | Description |
|---|---|
| Open Issues | Issues currently awaiting resolution |
| Closed Issues | Issues that have been resolved or closed |
| New Issues | Issues created during a selected period |
| Resolved Issues | Issues closed during a selected period |
| Resolution Time | Time taken to close an issue |

## Reporting Periods

Analytics should support:
- Last 7 days
- Last 30 days
- Last 90 days
- All available history
