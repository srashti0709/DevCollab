# DevCollab — Design System

## 1. Design Philosophy

DevCollab uses a modern, minimal and developer-focused interface.

- Design approach: Hybrid (Light + Dark themes)
- Inspiration: Linear, GitHub and Vercel
- Style: Clean, professional, consistent and responsive
- Primary font: Inter

- Font family: Inter
- Headings: Inter SemiBold / Bold
- Body: Inter Regular
- Buttons: Inter Medium

## 5. Buttons

Six reusable variants:

1. Primary
2. Secondary
3. Outline
4. Ghost
5. Danger
6. Icon

All buttons support hover, focus, active and disabled states.

## 6. Cards

Four reusable card types:

1. Standard Card
2. Statistic Card
3. Repository Card
4. Activity Card

Common properties:
- 12px border radius
- 16–24px padding
- Subtle border
- Theme-aware surfaces
- Consistent hover states

## 7. Form Components

- Text Input
- Password Input
- Search Input
- Dropdown / Select
- Textarea
- Checkbox
- Radio Button
- Toggle / Switch
- Date Picker
- Validation Messages

Input height: 44–48px.

## 8. Tables

Reusable tables for:
- Repositories
- Issues
- Pull Requests
- Contributors
- Team Members
- Activity Records

Features:
- Sorting and filtering
- Pagination
- Row hover states
- Status badges
- Responsive horizontal scrolling
- Loading and empty states

## 9. Navigation

- Collapsible left sidebar
- Top navigation bar
- Breadcrumbs
- Tabs
- Dropdown menus
- Mobile navigation drawer

Topbar includes search, notifications, theme switcher and user profile.

## 10. Supporting Components

- Status Badges
- User Avatars
- Tooltips
- Modals
- Toast Notifications
- Skeleton Loaders
- Empty States
- Pagination
- Progress Indicators

## 11. Status Colors

Status indicators will use consistent semantic colors:

- Success: Green
- Warning: Amber
- Error: Red
- Information: Blue
- Neutral: Gray

## 12. Accessibility

- Visible keyboard focus indicators
- Sufficient color contrast
- Keyboard-accessible navigation
- Clear form labels and validation messages
- Accessible names for icon-only buttons
- Consistent interaction states

## 13. Responsive Design

The design system will support:
- Desktop
- Tablet
- Mobile

Components must adapt to different screen sizes without losing important functionality.

## 14. Design Principles

1. Consistency across all pages.
2. Reusable components instead of duplicated UI.
3. Clear visual hierarchy.
4. Minimal visual clutter.
5. Accessible interactions.
6. Theme consistency.
7. Responsive layouts.
8. Data-focused dashboards.
