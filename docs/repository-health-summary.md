# Repository Health Summary

## Overview

Repository health provides maintainers with an overview of repository activity and maintenance status.

## Key Indicators

- Open and closed issues
- Open and merged pull requests
- Recent commit activity
- Contributor participation
- Outstanding review requests

## Purpose

These indicators help maintainers understand repository activity, identify pending work, and monitor collaboration patterns.

## Reporting

Repository health information should be presented through a summary dashboard with clear counts and activity trends.
