
# Contributor Guidelines

## Getting Started

1. Explore the repository structure.
2. Review existing issues before starting work.
3. Create a separate branch for each feature or fix.
4. Keep commits focused and descriptive.

## Pull Request Guidelines

- Provide a clear pull request title.
- Explain the purpose of the changes.
- Include relevant issue references.
- Respond to review feedback.

## Code Quality

Keep changes readable, maintainable and consistent with the existing project structure.
