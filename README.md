# DevCollab

**One platform. Every contribution. Better collaboration.**

DevCollab is a centralized GitHub collaboration and developer analytics platform that helps individual developers and teams manage repositories, issues, pull requests, and collaboration insights from one place.

## Tech Stack

- Frontend: React, JavaScript, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL, Prisma
- Cache and Sessions: Redis
- Background Jobs: BullMQ
- GitHub Integration: GitHub OAuth, GitHub App, Octokit
- Testing: Vitest, Supertest, Playwright
- Deployment: Docker, GitHub Actions
